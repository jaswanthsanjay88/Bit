**Body:**
Hey everyone,

I've been working on **BIT**, an open-source Android AI assistant and agent harness built from the ground up for complete privacy and local execution.

### What it does:
- **Autonomous Agent Harness:** Event-driven agent loop with GBNF grammar-constrained function calling, observation formatting, quality gates, and sandboxed terminal execution inside an isolated PRoot Linux environment.
- **Local LLM Engine:** Native llama.cpp runtime supporting GGUF models (Qwen 2.5, Gemma 2/3, Llama 3, Mistral) with configurable context, GPU offload, and thread tuning.
- **Local Speech & Audio:** Whisper STT via sherpa-onnx and neural TTS (Piper & Kokoro) run on-device without cloud roundtrips.
- **Privacy & Security:** Vector RAG memory vault stored locally with AES-256-GCM encryption. Zero bytes ever leave the device.
